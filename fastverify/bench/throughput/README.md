# bench/throughput — verifying MANY small proofs: throughput, cost per proof, sound batch verification

Big inputs (exports, build trees, challenge exports) are regenerated by the scripts.

| file | what |
|---|---|
| `corpus/problems.py` | 108 competition-style problems (statement, proof, style) on Lean 4.33.1 + Mathlib 0df444a, all elaborated in bwrap; 20 styles (norm_num, decide, omega, nlinarith, positivity, ring, field_simp, simp, fun_prop, aesop, grind, tauto, rfl/GMP, induction, term-mode lemma applications) |
| `corpus/gen.py OUT [--names a,b,...]` | `OUT/challenges/<name>` (statement := sorry, `comparator.json` Lean-kernel only) and `OUT/projects/<name>` per problem; 15 AI-prover cheating variants `OUT/projects/<name>--<kind>` (sorry, sorry in a have, sorry behind a macro, sorryAx written out, `set_option warn.sorry false` + sorry, extra axiom, the theorem itself added as an axiom by `run_cmd`/`addDecl`, native_decide x2, weaker statement, changed constant, a statement-changing local `Mod ℕ` instance, ill-typed `addDecl` under `debug.skipKernelTC`; harmless look-alikes: local notation, `@[implemented_by]`); `BATCH` = all problems in one project / one challenge; `cases.json` with the expected official verdicts |
| `runq.sh QUEUE LANES` | runs `CASE PRESET MODE [@label] [fastverify args]` lines through a (frozen) package, LANES at a time (`R`, `CORPUS`, `FV_PKG`, `THREADS`, `WS` env; runs in `R/runs/<case>.<preset>.<mode>/`, one line per run in `R/runs/done.tsv`); MODE `src` = challenge built officially by the package, `pin` = the official challenge export of the `src` run given + pinned |
| `table.py RUNROOT...` | one TSV row per run (stage seconds, verdict, trust, export size, build option, toolchain) |
| `mkattempts.py CORPUS OUT pos|mix|neg` | an attempts directory for `tools/batchverify.py` (`mix` = every problem with a cheating variant gets the variant) |
| `mkstream.py CORPUS OUT [--n N --fail F --cheat C --seed S]` | a synthetic stream of model-like attempts (honest / not compiling / generic cheats: `sorry`, `sorryAx`, `warn.sorry false` + sorry, an extra axiom) packed into batches with at most one attempt per problem; `labels.json` |
| `stream.sh STREAM OUT PSET SHA [batchverify args]` | verifies a stream batch by batch with `tools/batchverify.py` (one snapshot cache) and tallies every verdict against its label (exit 1 on any ACCEPT of a REJECTED-labelled attempt) |
| `test/test-batchverify.sh [WORK]` | regression test of `tools/batchverify.py` (`tests/batchverify`, 16 problems, 18 rows: official flow on the positive batch; cheating variants, a non-compiling attempt, a misspelt theorem name, an attempt importing another attempt and two no-cross-credit cases REJECTED; honest proofs and harmless look-alikes ACCEPTED; a wrong challenge pin gives no ACCEPTED) |

`tools/batchverify.py` (the sound batch verifier itself) is documented in its header.

Example (on hosts with NFS, use a node-local copy of the trusted workspace):
```
python3 -I corpus/gen.py $SCRATCH/tp/corpus
printf 'nt_prime_1009 reference src\nnt_prime_1009 sound pin\n' > q
R=$SCRATCH/tp/r CORPUS=$SCRATCH/tp/corpus FV_PKG=$FASTVERIFY THREADS=16 ./runq.sh q 1
python3 -I table.py $SCRATCH/tp/r
# batch: official problem-set challenge = the challenge.export of a reference run of BATCH
printf 'BATCH reference src\n' > qb; R=$SCRATCH/tp/r CORPUS=$SCRATCH/tp/corpus FV_PKG=$FASTVERIFY THREADS=32 ./runq.sh qb 1
mkdir -p pset; cp $SCRATCH/tp/r/chx/BATCH/challenge.export pset/; cp $SCRATCH/tp/corpus/challenges/BATCH/comparator.json pset/
python3 -I mkattempts.py $SCRATCH/tp/corpus att mix
$FASTVERIFY/tools/batchverify.py --pset pset --attempts att --out bv1 --challenge-sha256 $(sha256sum pset/challenge.export | cut -c1-64) \
    --threads 32 --snapshot-cache $SCRATCH/tp/snap
```
