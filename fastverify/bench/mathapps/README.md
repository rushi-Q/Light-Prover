# bench/mathapps — math formalizations on the trusted toolchain

Public Lean projects at a commit that pins EXACTLY the package's trusted Mathlib (`db584cd6` = tag v4.33.0, ported by the
one-commit toolchain bump to `0df444a` = v4.33.1, as in `bench/bigprojects`), so the whole fast path (B1/B3 planner +
zygote + merge, E1, CS) applies with no version port; each against a challenge built by the official Lean, through
`--preset sound`, `fast-exact` and the official flow.

| file | what |
|---|---|
| `repos.txt`, `tools/scan.sh SRCROOT URL...` | candidate math repositories and the scanner (partial clone, no code run): HEAD toolchain + every commit whose toolchain is v4.33.x, with its Mathlib revision |
| `projects.tsv` | name, repository, commit, pin, port edits, solution module, challenge theorems, notes |
| `challenges/<name>/` | hand-written clean challenges (statement copied with the project file's imports / opens / variables; `sorry` proofs); `hopf` uses the repository's OWN comparator challenge (generated by the tools) |
| `tools/fetch.sh NAME [ROOT]` | clone, export the pinned commit to `ROOT/projects/NAME`, apply the port, write `ROOT/projects/NAME-challenge` |
| `tools/runall.sh NAME THREADS [ROOT] [PRESETS]` | one sound run that builds + pins the official challenge export, then the presets (default `sound reference`; `fast-exact` is retired and refused) against the pinned challenge, then `bigprojects/tools/collect.py`; runs in `ROOT/runs/NAME-*` |
| `tools/iae-runs.sh ROOT THREADS NAME...` | `--preset sound` against the pinned challenge with the opt-in planner item `sound-fast-path=importarts-empty` instead of `sound-fast-path` (`TAG=iae`) |
| `tools/official-export.sh DIR OUT [ELAN_LOCAL WS_LOCAL EXPORTER]` | the OFFICIAL lean4export (the package's pinned E0 binary) on a build tree shipped from another host (export identity / timing) |

Workspaces: `bench/bigprojects/tools/mkws.sh NAME ROOT` (packages shared with the trusted Mathlib workspace are symlinked, extra
packages cloned at their manifest revisions and built OFFLINE in bwrap with the official lake). Runs:
`bench/bigprojects/tools/run.sh NAME PRESET THREADS ROOT [args]`.

Example (node-local package/toolchains from `bench/shapes/mklocal.sh $SCRATCH/local`):
```
tools/fetch.sh camcombi $SCRATCH/ma
TRUSTED_WS=$SCRATCH/local/ws TC=$SCRATCH/local/elan/toolchains/leanprover--lean4---v4.33.1 \
  ../bigprojects/tools/mkws.sh camcombi $SCRATCH/ma
FV=$SCRATCH/local/fv tools/runall.sh camcombi 16 $SCRATCH/ma
```
